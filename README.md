# 看看学 · 看视频学拼音生字 + 数学练习

一个 Chrome 浏览器扩展，包含两种学习模式，全程**语音播报、点一点就能玩**，适合低年级孩子：

- 📖 **语文**：小朋友在 B站看完视频后，扩展根据视频**字幕**自动出几道**拼音 / 生字小游戏**。
- 🔢 **数学**：随时点侧边栏的「🔢 数学练习」做**加减法**（含进位 / 退位），**不依赖视频、纯本地生成、得数绝对正确**。

两种模式**共用**同一套答题引擎、语音播报、奖励动画、错题本和做题记录。

## 它是怎么工作的

1. 孩子在浏览器里**登录 B站**，打开一个**有字幕**的视频（比如「芳斯塔夫」的视频）。
2. 扩展自动读取这个视频的字幕，右侧**侧边栏**会显示「视频准备好啦」。
3. 看完后点一个大按钮「🎮 我看完啦，开始玩！」。
4. 扩展把字幕交给 **DeepSeek AI** 挑出生字、出题；做题时会**自动朗读**，
   答对有掌声和星星，答错温柔提醒、不批评。

## 出题原则：紧扣视频内容

- 考核点是**视频里反复出现的高频词 / 关键概念**（优先词语，而不是随便的生字）。
- 每道题都尽量配一句**视频字幕里的原文例句**（含考核词，会自动朗读），让练习和刚看的内容强相关。
- 有 DeepSeek 密钥时：AI 通读字幕挑高频词、摘原文例句出题。
- 没有密钥/离线时：本地用 n-gram 词频统计高频词、从原文找例句出题（兜底也保证内容相关）。

## 题型（都以听声音 + 点击为主）

- 🔊 **听词选词**：听词语读音，从几个词里点对的（干扰词也尽量来自本视频）。
- 🅰️ **选拼音**：这个词的拼音是哪个？
- 🎵 **声调选择**：这个字是第几声？
- 🔤 **选声母**：这个字的声母是哪个？

拼音、声调一律由 `pinyin-pro` 校验，保证答案正确（不会被 AI 读错音误导）。

## 数学练习（加减法）

- 打开侧边栏 → 点「🔢 **数学练习**」即可开始，**不需要视频、不需要登录、不需要联网**。
- 题型：**加 / 减 / 加减混合**，可选 **20 以内 / 100 以内**，并可**优先出进位、退位题**（如 8+5、13-5）。
- 题目大号显示算式 `8 + 5 = ?`，自动朗读「8 加 5 等于几」，从 4 个数字里点对的。
- **得数与选项一律由本地计算**，绝对正确；干扰项贴近答案（±1、±2、进退位易错的 ±10）。
- 可选 **AI 配应用题情境**（需填 API 密钥）：给算式配一句生活化情境（如「小明有 8 个苹果，又买了 5 个」），
  但**得数始终本地计算**，AI 只负责情境文字，绝不参与判分。
- 数学题同样进入**错题本 / 做题记录**，可复习。

在设置页「数学练习（加减法）」一栏调整数值范围、运算类型、是否进退位、是否启用 AI 情境。

## 安装（家长操作一次即可）

### 方式一：下载安装包（推荐，免编译）

1. 到 [**Releases**](https://github.com/zxysdtc/kankan-learn/releases/latest) 下载最新版
   [`kankan-learn-v0.3.0.zip`](https://github.com/zxysdtc/kankan-learn/releases/download/v0.3.0/kankan-learn-v0.3.0.zip)，解压到一个固定文件夹。
2. 地址栏输入 `chrome://extensions`，打开右上角「**开发者模式**」。
3. 点「**加载已解压的扩展程序**」，选择刚解压出来的文件夹。
4. 点扩展图标 ⭐，或在任意 B站视频页右侧打开侧边栏。

### 方式二：从源码构建

```bash
cd kankan-learn
npm install
npm run build
```

然后在 Chrome：

1. 地址栏输入 `chrome://extensions`，打开右上角「**开发者模式**」。
2. 点「**加载已解压的扩展程序**」，选择本项目里的 `dist/` 文件夹。
3. 点扩展图标 ⭐，或在任意 B站视频页右侧打开侧边栏。

## 设置

右键扩展图标 →「选项」，或在 `chrome://extensions` 里点「扩展程序选项」：

**AI 出题接口（兼容任意 OpenAI 格式接口）**
- **服务预设**：DeepSeek / OpenAI / 自定义，选了会自动填好地址和模型，也可手改。
- **接口地址 (Base URL)**：如 `https://api.deepseek.com`、`https://api.openai.com/v1`，
  或你自建/中转的 OpenAI 兼容地址（会自动补 `/chat/completions`，也可直接填完整 endpoint）。
- **模型名称**：如 `deepseek-chat`、`gpt-4o-mini`。
- **API 密钥**：`sk-...`。不填则使用内置题（仍紧扣视频内容）。

**练习设置**
- **每个视频出几道题**：建议 3~5 道。每次实际会多出几倍题量构成「题库」，
  做题时**随机抽取**设置数目的题，孩子多玩几次也不会每次都是相同次序、相同的题。
- **难度**：
  - 🌱 简单：以「听词选词」为主（听 + 认，最友好）。
  - 🌿 中等：「听词选词」+「选拼音」混合。
  - 🌳 挑战：以「选拼音 / 选声母」为主，干扰项用**近音**（平翘舌 zh/z、前后鼻音 an/ang、相近声调）。
- **音频播放方式**：
  - 🔊 自动播放：进入题目自动朗读（识字弱的孩子推荐）。
  - ✋ 手动播放：进入题目不发声，孩子点喇叭才朗读，锻炼独立听辨。
- **音量 / 语速**：孩子识字弱时语速建议调慢（0.7~0.8）。

**做题记录**
- 设置页底部「做题记录」会列出孩子每一轮的做题历史：时间、视频、一遍答对的题数与正确率、难度、点错次数，
  并汇总总体一遍答对率，方便家长了解孩子的进步。可一键清空。

密钥、设置与做题记录只保存在本机 `chrome.storage.local`，不会上传别处。

## 使用前提

- 必须**登录 B站**，否则拿不到字幕。
- 视频必须**有字幕**（人工字幕或 AI 字幕都行）。没有字幕的视频会友好提示换一个。

## 开发

```bash
npm run dev     # Vite 开发模式（热更新）
npm run build   # 产出 dist/
```

目录说明见项目内 `src/`：
- `lib/`：字幕获取（`bili.ts`）、AI 出题（`llm.ts`）、拼音工具（`pinyin.ts`）、
  离线兜底出题（`quizgen.ts`）、数学加减题本地生成（`mathgen.ts`）。
- `background/`：后台 service worker，负责跨域调 B站接口、调 AI。
- `content/`：注入 B站视频页，识别当前视频、监听切换与播放结束。
- `sidepanel/`：侧边栏答题界面（题型、语音、音效、奖励动画）。
- `options/`：家长设置页。

## 已知边界 / 后续可扩展
